hc session and cancelled with Esc each time.

- bash-, write-, fetch-permission: the three permission boxes (write-permission-cursor2: after one Down).
- question, question-multi: AskUserQuestion with one question, then two (the first multiSelect).
- hooks.jsonl: what a PermissionRequest and a Notification hook got at each (ids dropped).
